These devlogs were made as part of Hack Club's Stardance program, and are re-uploaded here for archival reasons. They're subdivided into folders named by the devlog's datetime. Each contain the Markdown message with a YAML frontmatter of the time logged, and the accompanying image/video asset uploaded to the site. Note that the media formats are misnomers: the site does not serve the original form.

If the site is still up, all of these devlogs are available at their original source [here](https://stardance.hackclub.com/projects/11289).

If not, the site is (somewhat) archived [here](https://archive.md/f82gu/image) and in the HTML fetch used for generating these devlogs [here](./snapshot.html). It seems like Stardance is trying to block scraping, so the regular "webpage" archival doesn't work and only shows a loading screen. The Wayback Machine doesn't seem to work either, unfortunately.

If you're curious, I made [a little script](./src/generate-folders-images.ts) to extract the folders, starter metadata, and media. Markdown is extracted manually, as the raw markdown is only accessible when being logged in and editing a post and I'd rather not pull in another NPM dependency when I could get the real deal.
